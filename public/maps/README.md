# Official maps

No official SEMICON West 2026 PDF/image was provided or successfully fetched. No approximate geometry is bundled.

Drop licensed official PDFs/images here before building, then import them from Explore > Venue maps on the device. Files in this directory are precached when under the configured 8 MB per-file limit. For automatic discovery, add entries to src/data/maps.ts (documented in README).

For immediate use, import a map through the app. It is stored as a Blob in IndexedDB, separate from the personal JSON backup. Download saved maps from the viewer for transfer to another device.
